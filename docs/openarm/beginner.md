## 一、什么是机械臂？

### 1.1 简单理解

想象一下你的手臂：
- **肩膀** - 可以前后、左右转动（2个自由度）
- **上臂** - 连接肩膀和肘部
- **肘部** - 可以弯曲
- **前臂** - 可以旋转
- **手腕** - 可以多方向转动
- **手指** - 可以抓东西

**机械臂就是模仿人类手臂的机器人。**

### 1.2 OpenArm 是什么？

OpenArm 是一个 **7 自由度（7 DOF）** 的机械臂：

```
DOF = Degree of Freedom = 自由度 = 能动的方向数量
```

| 关节 | 位置 | 能做什么 |
|------|------|----------|
| J1 | 肩膀（左右） | 左右转 |
| J2 | 肩膀（前后） | 前后转 |
| J3 | 上臂 | 扭转 |
| J4 | 肘部 | 弯曲 |
| J5 | 前臂 | 旋转 |
| J6 | 手腕 | 弯曲 |
| J7 | 手腕 | 旋转 |
| J8 | 夹爪 | 抓取 |

**类比**：J1-J2 像你的肩膀，J4 像你的肘部，J6-J7 像你的手腕，J8 像你的手指。

## 二、常见术语解释（新手必读）

### 2.1 基础术语

| 术语 | 大白话解释 | 类比 |
|------|-----------|------|
| **DOF** (Degree of Freedom) | 能动的方向数量 | 你的手臂有7个能动的关节 |
| **扭矩** (Torque) | 转动的力气 | 拧瓶盖时用的力 |
| **减速比** | 速度换力气的比率 | 骑自行车上坡时换低速挡 |
| **编码器** (Encoder) | 记录转动角度的传感器 | 你闭着眼也知道手在哪 |
| **CAN 总线** | 电机之间的"电话线" | 让电机们互相通信 |
| **BLDC 电机** | 无刷直流电机 | 比普通电机更耐用、更精准 |
| **转子** (Rotor) | 电机里转动的部分 | 风扇的叶片 |
| **定子** (Stator) | 电机里不动的部分 | 风扇的外壳 |

### 2.2 零件术语

| 术语 | 大白话解释 | 长什么样 |
|------|-----------|----------|
| **CNC 铝件** | 用机器精确切割的铝制零件 | 银白色金属块，很光滑 |
| **钣金件** | 折弯成型的金属薄板 | 像铁皮盒子 |
| **深沟球轴承** | 让零件顺畅旋转的圆环 | 甜甜圈形状，里面有小球 |
| **法兰轴承** | 带固定孔的轴承 | 轴承+小法兰盘 |
| **阶梯螺栓** | 一头粗一头细的螺栓 | 像台阶一样 |
| **T型螺母** | 能卡在铝型材槽里的螺母 | 形状像字母T |
| **铝型材** | 标准化的铝制方管 | 长条形铝材，有槽可以装东西 |

### 2.3 工具术语

| 术语 | 大白话解释 | 用来做什么 |
|------|-----------|-----------|
| **万用表** | 测电压、电流、电阻的表 | 检查电路是否正常 |
| **CAN 分析仪** | 让电脑和电机对话的工具 | 配置电机参数 |
| **卡尺** | 精确测量长度的尺子 | 检查零件尺寸 |
| **扭矩扳手** | 能控制拧紧力度的扳手 | 防止螺丝太松或太紧 |
| **烙铁** | 焊接用的热工具 | 连接电线 |

## 三、认识你的零件

### 3.1 电机（最重要！）

OpenArm 使用 4 种电机，怎么区分？

```
┌─────────────────────────────────────────────────────────────┐
│                    电机识别指南                              │
├─────────────────────────────────────────────────────────────┤
│  大电机 (J1/J2)     │  中电机 (J3)    │  小电机 (J4-J8)    │
│  DM-J8009P          │  DM-J4340P      │  DM-J4310          │
│  重量: 896g         │  重量: 362g     │  重量: 300g        │
│  像拳头大小          │  像鸡蛋大小     │  像乒乓球大小       │
│  肩膀用             │  上臂用         │  前臂/手腕用        │
└─────────────────────────────────────────────────────────────┘
```

**快速识别技巧**：
- 看重量标签 - 包装上会写
- 看大小 - 大的给肩膀，小的给手腕
- 看型号 - 最后几位数字越大，电机越大

### 3.2 螺丝（最容易搞混！）

**螺丝命名规则**：`M` + 直径 + `x` + 长度

```
M3x6 = 直径3mm，长度6mm的螺丝
M4x10 = 直径4mm，长度10mm的螺丝
```

**快速识别方法**：

| 螺丝 | 用在哪 | 怎么认 |
|------|--------|--------|
| M3x6 | 小零件固定 | 最短最细，用的最多（146个！） |
| M3x8 | 中等固定 | 比M3x6长一点 |
| M3x15 | 电机安装 | 明显更长 |
| M3x18 | 特殊位置 | 最长的M3螺丝 |
| M4x6 | 外壳固定 | 比M3粗 |
| M4x8 | J1/J2安装 | 中等粗细 |
| M4x10 | 大零件固定 | 较粗较长 |
| M5x10 | 底座固定 | 最粗的螺丝 |

**建议**：买个螺丝分装盒，按型号分类存放！

### 3.3 轴承

```
┌─────────────────────────────────────┐
│         轴承识别                    │
├─────────────────────────────────────┤
│  MR106ZZ1  │  小轴承，用于J7关节    │
│  FL6700ZZ  │  法兰轴承，用于J6      │
│  FL6803ZZ  │  法兰轴承，用于J4      │
│  MR126ZZ   │  小轴承，用于夹爪      │
└─────────────────────────────────────┘
```

**识别技巧**：
- MR开头 = 普通轴承（甜甜圈形状）
- FL开头 = 法兰轴承（带小底座）
- 数字越大，轴承越大

### 4.2 工作环境

**理想的工作台**：
- ✅ 平整的桌面
- ✅ 光线充足
- ✅ 有电源插座
- ✅ 有地方放零件盒
- ❌ 不要在地上组装（会丢螺丝）
- ❌ 不要在床上组装（会滚动）

### 4.3 个人准备

**开始前**：
- 洗手（油污会影响零件）
- 穿工作服（不要穿毛衣，会粘毛）
- 准备好眼镜（如果需要）
- 准备一杯水（组装需要耐心）

## 五、分阶段学习路径

### 🎯 阶段一：认识零件（1-2小时）

**目标**：能叫出每个零件的名字

**步骤**：
1. 打开零件包装
2. 对照本文档的"认识你的零件"章节
3. 把零件按类型分组
4. 用卡尺测量几个螺丝，验证型号

**验收标准**：
- [ ] 能区分4种电机
- [ ] 能区分8种螺丝
- [ ] 能区分4种轴承

### 🎯 阶段二：学习工具（1小时）

**目标**：会用基本工具

**步骤**：
1. 学会读卡尺
2. 学会用万用表测通断
3. 学会用内六角扳手

**练习**：
- 用卡尺测量10个不同零件
- 用万用表测试一根电线是否导通
- 用内六角扳手拧紧一个螺丝

**验收标准**：
- [ ] 卡尺读数误差 < 0.1mm
- [ ] 万用表能正确显示通断
- [ ] 螺丝拧紧但不滑丝

### 🎯 阶段三：简单组装（2-3小时）

**目标**：完成工站1（来料检验）

**步骤**：
1. 阅读完整 SOP 的工站1
2. 按步骤检验电机
3. 按步骤检验加工件
4. 按步骤清点标准件

**验收标准**：
- [ ] 所有电机外观无损坏
- [ ] 能用万用表测电机空载电流
- [ ] 标准件数量正确

### 🎯 阶段四：进阶组装（持续学习）

**目标**：逐步完成其他工站

**建议顺序**：
1. 工站2（电机配置）- 需要CAN分析仪
2. 工站3（底座组装）- 最容易上手
3. 工站4-5（关节组装）- 核心技能
4. 工站6（夹爪）- 需要焊接
5. 工站7（布线）- 需要细心
6. 工站8（测试）- 最后一步

## 六、常见错误与避免

### 6.1 新手最常犯的错误

| 错误 | 后果 | 如何避免 |
|------|------|----------|
| 螺丝拧太紧 | 滑丝、损坏零件 | 使用扭矩扳手，感觉阻力就停 |
| 螺丝拧太松 | 零件松动 | 拧紧后回转1/4圈再拧紧 |
| 轴承装反 | 运动不顺畅 | 看开口方向，朝向转子 |
| 电机方向装错 | 无法组装 | 参考图片，确认端口方向 |
| 忽略左右臂差异 | 组装失败 | 每一步都确认是左臂还是右臂 |

### 6.2 如果搞砸了怎么办

**别慌！** 每个人都会犯错。

**螺丝滑丝了**：
1. 停止强行拧
2. 用更大的螺丝（如果孔允许）
3. 或者用螺纹修复套件

**零件装反了**：
1. 拆下来重装
2. 检查是否有损坏
3. 记录下来，下次注意

**不知道下一步怎么办**：
1. 停下来，深呼吸
2. 重新阅读SOP
3. 拍照发到社区求助
