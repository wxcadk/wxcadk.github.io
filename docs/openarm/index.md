## 一、项目概述

**OpenArm** 是 Enactic 公司开源的 7 自由度仿人机械臂，专为物理 AI 研究和接触密集型环境部署设计。

### 1.1 核心参数

| 参数 | 规格 |
|------|------|
| 自由度 | 7 DOF（+1 夹爪） |
| 额定负载 | 4.1 kg（最差姿态保持1分钟） |
| 峰值负载 | 6.0 kg（3秒移动+1秒保持） |
| 末端执行器重量（含） | 从负载中扣除（如1.5kg夹爪→额定2.6kg） |
| 通讯协议 | CAN 总线 |
| 供电 | 24V（J1/J2支持24-48V） |
| 双臂系统价格 | ~$6,500 USD（含所有零部件） |

### 1.2 电机规格

| 电机型号 | 安装位置 | 额定扭矩 | 峰值扭矩 | 减速比 | 重量 |
|---------|---------|---------|---------|-------|------|
| DM-J8009P-2EC | J1, J2（肩部） | 20 Nm | 40 Nm | 9:1 | 896g |
| DM-J4340P-2EC | J3（上臂） | 9 Nm | 27 Nm | 40:1 | 362g |
| DM-J4340-2EC | J4（肘部） | 9 Nm | 27 Nm | 40:1 | 362g |

所有电机均为 24V BLDC，配备 14-bit 磁编码器（双编码器），CAN 接口。

## 三、流水线工站设计

### 3.1 总体流程图

```
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐

│ 来料检验 │   │ 电机配置 │   │ 底座+J1J2│   │ J2J3+J3J4│   │ J4J5+J5J6│   │ 夹爪/末端│   │ 布线+外壳│   │ 总装测试 │
│ 预处理   │   │ ID分配   │   │ 子组件   │   │ 子组件   │   │ J7 子组件│   │ 子组件   │   │ 电气连接 │   │ 质检包装 │
```

**预估总工时：150-225 分钟/臂（2.5-3.75 小时）**

---

### 3.2 工站1：来料检验与预处理（5-10分钟/套）

**目标**：确保所有零部件合格，按工站分拣

**操作步骤**：

1. **电机检验**
   - 外观检查：无划痕、变形、端子损坏
   - 空载电流测试：24V供电，电流应<0.5A
   - CAN通讯测试：用测试工具验证每个电机可被识别
   - 记录电机序列号

2. **加工件检验**
   - CNC铝件：关键配合面尺寸抽检（卡尺），表面光洁度
   - 钣金件：孔位精度、折弯角度
   - 3D打印件：无翘曲、层间结合良好

3. **标准件清点**
   - 按BOM逐项清点螺丝、轴承、垫圈
   - 分装到对应工站的料盒中

4. **电气件检验**
   - 线缆：导通测试、插头无松动
   - PCB Hub：目视检查焊点
   - 电源：空载电压测试（24V±0.5V）

**工具/设备**：
- 万用表、CAN分析仪、卡尺
- 24V测试电源
- 物料分拣盒（按工站编号）

**质量检查点**：
- [ ] 所有电机CAN通讯正常
- [ ] 加工件尺寸合格
- [ ] 标准件数量齐全

---

### 3.3 工站2：电机ID配置（10-15分钟/套）

**目标**：在装配前完成所有电机的ID分配和基本参数设置

**⚠️ 关键前提**：必须在组装前完成！组装后难以访问电机配置端口。

**操作步骤**：

1. **连接测试环境**
   - 将电机逐个连接到CAN测试工装
   - 通过 USB2CANFD 转换器连接电脑

2. **分配电机ID**

| 关节 | 电机ID | Master ID |
|------|--------|-----------|
| J1 | 0x01 | 0x11 |
| J2 | 0x02 | 0x12 |
| J3 | 0x03 | 0x13 |
| J4 | 0x04 | 0x14 |
| J5 | 0x05 | 0x15 |
| J6 | 0x06 | 0x16 |
| J7 | 0x07 | 0x17 |
| J8（夹爪） | 0x08 | 0x18 |

3. **基本参数验证**
   - 验证编码器读数正常
   - 设置零位偏移（后续精调）
   - 记录每个电机的ID和序列号对应关系

4. **标签标记**
   - 在每个电机上粘贴ID标签
   - 标注所属关节（J1-J8）

**工具/设备**：
- CAN分析仪 + USB2CANFD转换器
- 配置电脑 + Damiao配置软件
- 标签打印机

**质量检查点**：
- [ ] 所有电机ID已正确分配
- [ ] CAN通讯测试通过
- [ ] 标签已粘贴

---

### 3.4 工站3：底座 + J1-J2 子组件组装（20-30分钟/套）

**目标**：完成底座组装和肩部关节子组件

#### 3.4.1 底座组装

1. 将底板（CNC Al6061）放在平整台面上
2. 将 750mm 60x60 铝型材立在底板上，确保底板较长边的两个孔在型材前方
3. 在铝型材两侧各安装一个侧支架
4. ⚠️ 提前在铝型材槽内插入T型螺母
5. 对齐支架孔位，用 M6x12 螺丝紧固
6. 安装 30°-60° 加固支架，用 M6x12 螺丝固定到底板和铝型材

#### 3.4.2 J1-J2 子组件

**⚠️ 左右臂差异**：J1_B 零件在左臂组装时方向不同，需特别注意。

1. 将 J1 电机背面安装到 J1_A，用 5 个 M4x10 螺丝
   - 确保电源和通讯端口可访问
   - 电机已配置 ID:0x01, Master ID:0x11
2. 将 J1_B 安装到电机，用 3 个 M4x8 螺丝
   - 机械限位器朝向电机电源端口，位于上方
3. 将 J1_C 安装到 J1 转子，用 6 个 M5x10 螺丝
4. 将 J1_D 安装到 J1_C，用 2 个 M4x10 螺丝
5. 将 J1_E 安装到 J1_C，用 3 个 M4x10 螺丝
6. 将 DM8009 电机 J2 插入 J1_D 和 J1_E 之间
   - 端口朝向 J1
   - J2 背面朝向 J1_E
7. 用 2 个 M4x8 螺丝将 J1_E 连接到 J2
8. 用 3 个 M4x8 螺丝将 J1_D 连接到 J2

**质量检查点**：
- [ ] 底座稳固，铝型材垂直
- [ ] J1 电机端口朝前
- [ ] J2 电机端口朝向 J1
- [ ] 所有螺丝按规定扭矩紧固
- [ ] 左右臂 J1_B 方向正确

---

### 3.5 工站4：J2-J3 + J3-J4 子组件组装（20-30分钟/套）

#### 3.5.1 J2-J3 子组件

1. 将 J2_A 与 J2_B 用 2 个 M4x10 螺丝连接
2. 将 J2_C 覆盖在 J2_A 和 J2_B 上，对齐孔位
3. J2_C 连接到 J2_A：4 个 M4x6 螺丝
4. J2_C 连接到 J2_B：4 个 M4x6 螺丝

#### 3.5.2 J3-J4 子组件

1. 将 J4_A 安装到 J3 电机，用 6 个 M3x6 螺丝
   - ⚠️ 确保两个 Power+CAN 端口朝向前方和后方
   - 💡 J3 电机通讯端口保持在右侧
2. 将 FL6803ZZ 轴承安装到 J4_B
3. 将 J4_B 放在 J4_A 内侧，对齐孔位（暂不紧固）
4. 小心将 J4 电机滑入 J4_A 和 J4_B 之间
   - 对齐 J4_B 上的孔位
   - Power+CAN 端口位置参照图片
5. 用 4 个 M3x6 螺丝将 J4 固定到 J4_B
6. 用 6 个 M3x6 螺丝将 J4_A 固定到 J4_B
7. 用 6 个 M3x6 螺丝将 J4_A 固定到 J4 电机
8. 插入支柱 AETTS8-61-SC0-M3-N3，用 2 个 M3x6 螺丝固定

**质量检查点**：
- [ ] 轴承 FL6803ZZ 正确安装
- [ ] J3/J4 电机端口方向正确
- [ ] 所有螺丝紧固

---

### 3.6 工站5：J4-J5 + J5-J6-J7 子组件组装（25-35分钟/套）

#### 3.6.1 J4-J5 子组件

1. 将 J4_C 安装到 J4 电机转子，用 6 个 M3x6 螺丝
2. 将 J4_D 安装到 FL6803ZZ 轴承上
3. 将 J4_E 安装到 J4_C，用 6 个 M3x6 螺丝
   - ⚠️ J4_E 与 J4_C 上的机械限位器对齐
4. 将 J5 电机放入 J4_D 和 J4_E 之间，用 6 个 M3x6 螺丝固定
   - Power+CAN 端口朝前后方向
   - 通讯端口朝向 J4_E
5. 插入两个支柱 AETTS8-74.2-SC0-M3-N3，用 M3x6 螺丝固定

#### 3.6.2 J5-J6-J7 子组件

1. 将 FL6700ZZ 轴承安装到钣金件 J6_A，轻轻插入 J7_B 对齐
2. 对 J6_B 重复同样操作
3. 将 J5_A 安装到 J5 电机转子，用 6 个 M3x18 螺丝
4. 将 J6_B 安装到 J5_A，用 3 个 M3x8 螺丝
   - 确保 J6_B 对齐 J5_A 的机械限位器
5. 将 J6_A 安装到 J5_A，用 3 个 M3x8 螺丝
6. 将 J6_D 安装到 J6 电机，用 4 个 M3x6 螺丝
   - J6_D 上下与两个 Power+CAN 端口对齐
7. 将 J7_E 安装到 J6 转子，用 6 个 M3x6 螺丝
8. 将 J6 电机放入 J6_A 和 J6_B 之间，用 4 个 M3x6 螺丝固定到 J6_A
   - 通讯端口应与 J7_E 在一条直线上
   - 💡 右臂：J7_E 向右突出；左臂：向左突出
9. 将 J7_A 安装到 J7 电机，用 3 个 M3x8 螺丝
   - 顶部螺丝与 Power+CAN 端口对齐
10. 将 J7_C 安装到 J7 电机背面，用 2 个 M3x8 螺丝
    - 💡 左臂：J7_C 安装在相反侧
11. 将 MR106ZZ1 轴承插入 J7_D_right 的两个孔
    - 💡 左臂使用 J7_D_left
12. 将 J7 电机放入 J6_A 和 J6_B 之间
13. 将两个 J7_B 连接到 J7_A，每侧 2 个 M3x8 螺丝
14. 用阶梯螺栓 DBSY4-6-5 + 4个垫圈 SWSPS12-6-0.5 将 J7_D_right 连接到 J7_C 和 J7_E

**质量检查点**：
- [ ] 所有轴承正确安装
- [ ] J5/J6/J7 电机端口方向正确
- [ ] 左右臂差异已处理（J7_C, J7_D）
- [ ] 阶梯螺栓垫圈位置正确

### 3.7 工站6：夹爪/末端执行器子组件组装（20-30分钟/套）

#### 3.7.1 Follower 夹爪

1. 将 J8_A 与 J8_B 用 3 个 M3x6 螺丝连接
2. 将 rail_connector 安装到 J8 电机，用 6 个 M3x8 螺丝
   - 法兰对齐 J8 的两个 Power+CAN 端口
3. 将 MR126ZZ 轴承插入 swivel_link（两个轴承从相反方向插入）
4. 将 swivel_rotor 连接到 J8 转子，用 4 个 M3x8 螺丝
5. 用阶梯螺栓 DBSY4-5-4 将两个 swivel_link 连接到 swivel_rotor
   - ⚠️ 轴承开口侧朝向 swivel_rotor
6. 将线性导轨安装到 rail_connector，用 4 个 M3x5 螺丝
7. 用 KBBS3-6 螺栓将 rail_CNC_attachment 固定到滑块
   - rail_CNC_attachment 与 swivel_link 同方向延伸
8. 用阶梯螺栓 DBSY4-5-4 将 swivel_link 连接到 rail_CNC_attachment
9. 用 4 个 KBBS3-6 螺栓将夹爪颚安装到 rail_CNC_attachment
10. 将子组件安装到 J8 电机背面，用 4 个 M3x8 螺丝
    - 右臂：J8_A 对齐右颚
    - 左臂：J8_A 对齐左颚
11. 💡 夹爪表面建议使用 3M 防滑胶带

#### 3.7.2 Leader 末端执行器

1. 将 J8_A 与 J8_B 用 3 个 M3x6 螺丝连接
2. 用烙铁在 swivel_rotor_leader 中热嵌 2 个 M4x4 热嵌螺母
3. 在 right_pincer 和 left_pincer 中各热嵌 1 个 M4x4 热嵌螺母
4. 在 rail_connector_leader 中热嵌 4 个 M3x6 热嵌螺母
5. 将 MR126ZZ 轴承插入 swivel_link_leader
6. 将 rail_connector_leader 安装到 J8 电机，用 4 个 M3x8 螺丝
   - 法兰对齐 Power+CAN 端口
   - 插入 2 个 M3x15 螺丝加固
7. 将 swivel_rotor_leader 连接到 J8 转子，用 4 个 M3x12 螺丝
8. 用阶梯螺栓连接 swivel_link_leader 到 swivel_rotor_leader
9. 将线性导轨安装到 rail_connector_leader，用 4 个 M3x6 螺丝
10. 将 left_pincer 和 right_pincer 安装到滑块，各 2 个 M3x6 螺丝
    - 热嵌螺母朝向 swivel_link_leader
11. 用阶梯螺栓连接 swivel_link_leader 到 pincer
12. 将子组件安装到 J8 电机背面

**质量检查点**：
- [ ] 轴承方向正确（开口侧朝向 swivel_rotor）
- [ ] 热嵌螺母牢固（Leader）
- [ ] 线性导轨运动顺畅
- [ ] 左右臂差异已处理

### 3.8 工站7：布线 + 外壳安装（30-45分钟/套）

#### 3.8.1 臂部布线

**⚠️ 连接器很脆弱，插拔时务必握住连接器本体，不要拉扯线缆。**

**布线顺序**：

1. **J3-J4 布线**
   - J3 连接器→J3 电机（上臂），J4 连接器→J4 电机（肘部）
   - 所有线缆沿上臂背面走线
   - ⚠️ J4 连接器靠近钣金件，小心不要损伤线缆

2. **J4-J7 布线**
   - J5 连接器从背面连接到 J5 电机
   - 弯曲肘部到限位点，连接 J4 连接器到 J4 电机
   - 所有线缆沿臂背面走线
   - 连接 J6 和 J7 连接器（J6 电机可能较难触及，调整臂角度找到最佳插入位置）

3. **J7-J8 布线**
   - 将 J7-J8 线缆连接到 J7 电机底部连接器
   - 另一端连接到 J8 电机

4. **J1-J2 布线**
   - J1 和 J2 连接器插入对应电机
   - J1 线缆从机器人腋下穿向背面
   - J2 线缆连接后向下弯曲整理
   - ⚠️ J1/J2 线缆上的小白插头需小心对齐

#### 3.8.2 外壳安装

1. **J1-J2 外壳**
   - J2 线缆穿过 J1-J2_B
   - 关闭外壳，2 个螺丝固定

2. **J2-J3 外壳**
   - J3-J4 线缆穿过 J2-J3_B
   - J1-J2_A 的锁钉插入 J2 电机中心孔并上滑
   - 2 个螺丝固定

3. **J3-J4 外壳**
   - J3-J4_A 从前方安装，J3-J4_B 从后方安装
   - 4 个螺丝固定

4. **J4-J5 外壳**
   - 安装前将 J4-J7 线缆引导到臂内侧
   - 线缆导入 J4-J5_B 内槽
   - 4 个螺丝固定

5. **J6-J7 外壳**
   - ⚠️ 左右臂零件不同，仔细检查
   - 3 个螺丝固定

#### 3.8.3 胸部布线与外壳

1. **Hub 板安装**
   - 在每个肩部背面插入 HNTP6-6 T型螺母
   - 安装 Hub 板后盖和 PCB（CAN 连接器朝内）
   - 用螺丝紧固
   - ⚠️ 左右臂独立系统，各自 Hub 板

2. **Hub 板连接**
   - 连接 J1、J2、J3-J4 电机线缆到 Hub 板
   - 连接通讯线缆
   - 连接延长线缆
   - 确认接线与参考图一致
   - 整理线缆

3. **胸盖安装**
   - Chest-cover_A 从前方安装
   - Chest-cover_B 从后方安装
   - J2 和 J3-J4 线缆穿过 Chest-cover_B 的 U 型槽
   - ⚠️ 小心不要夹住通讯或延长线缆
   - 6 个螺丝固定

**质量检查点**：
- [ ] 所有线缆导通测试通过
- [ ] 走线无干涉运动
- [ ] 外壳安装牢固
- [ ] 左右臂差异正确处理

## 四、机器人组装 vs 家电组装：核心差异

| 维度 | 家电组装（空调/洗衣机） | OpenArm 1.0 组装 |
|------|------------------------|-----------------|
| **精度要求** | ±0.5-1mm | ±0.05-0.1mm（关节运动精度） |
| **校准步骤** | 基本无 | 每关节需独立标定（零位、限位、编码器） |
| **布线复杂度** | 线束标准化、插接为主 | 定制走线，关节过线需特别处理 |
| **测试流程** | 功能测试（通电→运行） | 关节测试→运动学标定→精度验证→负载测试 |
| **零件数量** | 50-200个（大量标准化） | ~100个（含精密件，公差要求高） |
| **装配工时** | 15-45分钟/台 | 150-225分钟/台 |
| **工人技能** | 标准化操作、短期培训 | 需理解机械/电气/软件，培训2-4周 |
| **良品率** | >99%（成熟工艺） | 90-95%（需调试返工） |

**机器人更耗时的核心原因**：
1. 🔧 校准步骤不可省略 — 每个电机需独立配置ID、校准零位
2. 🔌 布线非标 — 关节内部走线需配合运动范围，弯曲半径有要求
3. 💻 需软件联调 — CAN通讯测试、固件配置、运动学参数
4. 📏 精度验证耗时 — 重复精度、定位精度、负载测试
5. 🔩 零件种类多 — CNC件、钣金件、3D打印件混合，公差配合要求高

## 五、常见故障与预防

| 故障类型 | 根因 | 预防措施 |
|---------|------|---------|
| 电机通讯失败 | ID冲突/线缆虚接 | 组装前配置ID + 逐关节通讯测试 |
| 关节卡顿 | 轴承未到位/加工件毛刺 | 来料检验 + 装配夹具 |
| 精度不足 | 齿隙/校准偏差 | 双编码器 + 软件补偿 + 标定夹具 |
| 线缆断裂 | 弯曲半径过小/固定不当 | 参照官方走线 + 疲劳测试 |
| 零位偏移 | 组装时未锁零位 | 标准化校准夹具 + SOP |
| 电机烧毁 | 接线反接/过载 | 预先测试 + 保险丝 + 急停 |
| 螺丝松脱 | 未按规定扭矩 | 扭矩螺丝刀 + 检查清单 |

## 八、安全注意事项

1. **安装安全**：将 OpenArm 牢固固定在平整稳定的表面上，远离易碎物、易燃物、潮湿环境
2. **操作安全**：运行时确保无人体或物体进入运动范围，调整时先断电
3. **防护装备**：操作时佩戴安全眼镜，必要时穿安全鞋、戴手套
4. **急停准备**：始终连接急停按钮，测试前验证急停功能
5. **线缆安全**：连接器脆弱，插拔时握住本体，不要拉扯线缆
6. **负载限制**：注意额定负载包含末端执行器重量

## 九、持续改进建议

1. **数据收集**：每台记录各工站耗时、返工原因
2. **Top 3 故障分析**：每月统计返工数据，定位最常见故障
3. **SOP 迭代**：根据实际生产数据每季度更新 SOP
4. **工装优化**：针对高频返工点设计专用夹具
5. **培训认证**：关键工站（校准/布线）需技能认证，建议培训周期 2-4 周
